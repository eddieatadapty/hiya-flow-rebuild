# Hiya Growth Audit

**Live → https://eddieatadapty.github.io/hiya-flow-rebuild/**

Five ideas to turn more Hiya users into subscribers, each built into a clickable version of Hiya's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask which calls bother them, then name them on the paywall | +10–20% CR to purchase |
| 02 | Let them look up one number before they pay | +5–15% CR to purchase |
| 03 | Put 238K ratings and your press where people pay | +5–10% CR to purchase |
| 04 | Make the yearly price add up | +5–15% ARPU |
| 05 | Answer “Continue with Basic” with 3 months | +5–10% CR from Basic pickers |

Every price, rating and feature comes from Hiya's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Hiya. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
